# Bugcrowd

Program pages are at bugcrowd.com/engagements/<name>, for example /engagements/openai. They render late.

## Reading a program
- Use `map` with a wait for "Average payout". A wait for "$" returned an empty page, and "Rewards" matches the menu before the page loads.
- Payouts by severity are under "Payment reward chart".
