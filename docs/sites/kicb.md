# KICB

Personal online banking at KICB (Kyrgyzstan) is in the mobile app only.

## Web
- ibank.kicb.net is for companies: it says web access is for legal entities and redirects to corp.kicb.net.
- There is no web password reset for personal clients. It needs the KICB app or the bank: +996 312 62 01 01, reception@kicb.net.
