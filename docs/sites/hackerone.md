# HackerOne

Program pages render in the browser: `read` returns a short shell, and early reads show "Placeholder" rows. Use `map` with a wait for "Rewards summary".

## Scope
- The scope list downloads as CSV with `read` at hackerone.com/teams/<handle>/assets/download_csv.csv. Some programs return 404; read the program page then.
