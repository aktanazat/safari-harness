# Discover

The card account is at card.discover.com; sign-in and security codes run on portal.discover.com. There are several saved logins, so pass username aktanazat to `passwords fill`.

## Sign-in
- At "How can we send you a security code?" click Text, then Send Code. The code comes by text; the page moves to /otp/verifyCode.
- Password recovery asks for date of birth and SSN, which only the owner can give.

## Pages
- 5% categories: card.discover.com/cardmembersvcs/promotions/app/5percent.
- Help: card.discover.com/cardmembersvcs/helpcenter/action/mainPage.

## Chat
- Open chat by clicking `#fc-chaticon` from `repl`; "Message us" has no ref.
- The chat runs in a frame named "Chat" with a "Reply here" box and Send. Send "Talk to a live agent" to reach a person; one answered in about 5 minutes.
